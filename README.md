# RadCord 2.0

P2P-коммуникатор для локальных сетей и Radmin VPN. Вторая версия — переписана на C# (.NET 8) с WPF-интерфейсом для нативной производительности на Windows. Расширяет функционал первой версии: передача файлов, захват системного звука, несколько сетей одновременно.

---

## Что нового по сравнению с 1.0

- Нативный Windows-клиент (.exe без Python/зависимостей)
- Передача файлов в чате (chunked, с прогрессом)
- Захват **системного звука** (ProcessLoopback) — трансляция звука с ПК
- Поддержка нескольких Radmin/LAN-сетей одновременно в боковой панели
- MVVM-архитектура (CommunityToolkit)
- Встроенные системные звуки (подключение, сообщение, отключение)

---

## Возможности

- **Текстовые каналы** — чат с вложениями файлов (побайтовая передача по частям)
- **Голосовой чат** — реальное время, VAD, настройка порога через слайдер
- **Демонстрация экрана** — выбор монитора или окна, просмотр в отдельном окне
- **Системный звук** — трансляция аудио с компьютера (WASAPI ProcessLoopback)
- **Аудиомикшер** — раздельная регулировка громкости 0–200% для каждого участника
- **Горячие клавиши** — глобальные бинды мут/дифенс (любая клавиша или Mouse4/5)
- **P2P mesh** — Fleck WebSocket-сервер внутри + ClientWebSocket наружу
- **Автообнаружение** — сканирование подсети, автоподключение к участникам
- **Несколько сетей** — несколько Radmin VPN / LAN-сетей одновременно

## Структура проекта

```
Ds_2/
├── Core/
│   ├── MeshNetwork.cs              # P2P WebSocket mesh (Fleck сервер + ClientWebSocket)
│   ├── AudioManager.cs             # Захват и воспроизведение аудио (WASAPI, NAudio)
│   ├── ProcessLoopbackCapture.cs   # Захват системного звука (ProcessLoopback API)
│   ├── ScreenCapture.cs            # Захват экрана (System.Drawing)
│   ├── PeerDiscovery.cs            # Сканирование подсети, поиск участников
│   ├── Protocol.cs                 # Протокол: типы пакетов, упаковка байт
│   ├── SoundService.cs             # Системные звуки приложения
│   └── MessageCache.cs             # Кеш истории чата на диске
├── Models/
│   ├── Peer.cs                     # Участник (ник, аватар, состояние мута/дифенса)
│   ├── ChatMessage.cs              # Сообщение чата (текст / файл / системное)
│   ├── NetworkInfo.cs              # Сеть (имя, список участников)
│   └── VoiceChannelEntry.cs        # Запись в голосовом канале
├── ViewModels/
│   └── MainViewModel.cs            # Главный ViewModel (ObservableProperty, RelayCommand)
├── Views/
│   ├── MainWindow.xaml(.cs)        # Главное окно: сервер-бар, сайдбар, чат, участники
│   ├── SettingsDialog.xaml         # Настройки: аудио-устройства, VAD, горячие клавиши
│   ├── NetworkDialog.xaml          # Управление сетями (добавить, удалить, подключиться)
│   ├── ScreenPickerDialog.xaml     # Выбор монитора или окна для трансляции
│   ├── ScreenViewWindow.xaml       # Окно просмотра экрана участника
│   ├── SetupWindow.xaml            # Первый запуск: ник и цвет аватара
│   └── InputDialog.xaml            # Диалог ввода текста (создание канала и т.д.)
└── sound/                          # Встроенные системные звуки (mp3, упакованы в exe)
```

## Запуск

Требования: .NET 8 SDK, Windows 10/11 (x64)

```bash
dotnet run
```

Готовая сборка: `publish_release/RadCord.exe` — запускается без установки .NET.

При первом запуске — диалог выбора ника и цвета аватара.

## Протокол

Первый байт — тип пакета: голос, экран, аудио-поток, файл-чанк, системный звук, управляющее событие. Payload — raw bytes для медиа, JSON — для текста и событий. Полностью совместим с Python-версией (RadCord 1.0).

```
         └─────────────────────────────────────┘
                   прямые соединения, без координатора
```
